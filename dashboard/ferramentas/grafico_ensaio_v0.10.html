Aguardando o medidor
INFORMATIVO. As etapas são deduzidas pela carga lida na API (não pelo cronômetro do medidor) e os critérios abaixo são provisórios. Não substitui o ensaio registrado no medidor.
Aguardando o medidorAbra este gráfico pelo botão “📈 Analisar” do medidor, ou use “Abrir ensaio salvo” para analisar um ensaio que já terminou. Sem o medidor? Troque a “Fonte” para “API direto”.

Como usar

Segunda telaArraste esta janela para o outro monitor e use “Tela cheia” (ou F11). Ela continua recebendo os dados do medidor.
AproximarRoda do mouse, botões ＋ −, teclas + e −, pinça no toque.
Zoom verticalShift + roda sobre a faixa. Clique no título da faixa para dar “foco nos dados”.
MoverArrastar, ou setas ← →. Home ajusta tudo; duplo clique também.
MedirUm clique marca A, o seguinte marca B. A tabela mostra a diferença.
Ao vivo“Últimos 2 min” etc. mantém o gráfico acompanhando o presente.
ExportarUm botão só: PDF (1 página com o gráfico), imagem PNG, planilha CSV e “Ensaio para reabrir (.json)”, que pode ser aberto aqui depois com “Abrir ensaio salvo”.

Esta página só mostra dados: não comanda chave e não escreve no PLC/DSE. Os cartões de “Condições de aprovação” são conferência (o resultado oficial é o do medidor); passe o mouse ou toque num cartão para ver no gráfico de onde sai o valor. Na fonte “API direto” o resultado é só INFORMATIVO.
