Dados reais do medidor (CSV + TXT)

Anexe aqui os arquivos que o medidor baixa em Registro de aprendizado › Amostras › Arquivos: o CSV ("Só amostras", um ponto por segundo) e/ou o TXT ("Só resumo": gerador, parâmetros usados, resumo por etapa e eventos). Dá para anexar os dois de uma vez ("Baixar tudo"). Daqui saem os números REAIS para trocar as premissas do modelo e para comparar o ensaio real com a simulação.

No computador também dá para arrastar os arquivos até esta caixa. Os arquivos são lidos só no seu navegador.
