Como os dados do ensaio chegam ao PLC

Cada banco de teste (BT1 e BT2) tem seu próprio computador e seu próprio controlador do gerador. Os dois sempre mandam os dados do gerador para o PLC Ensaio Automático (SB_DSE). A seleção manual/automático — feita pelo Node-RED de seleção — decide para qual PLC o degrau é escrito e de qual PLC o valor salvo é lido de volta (SB_DB SNAP).

BT1 e BT2 são independentes: cada um tem seu próprio computador e seu próprio controlador, e os dois ficam acima e abaixo dos mesmos dois PLCs — nenhuma linha de uma trilha atravessa o espaço da outra. SB_DSE é a leitura contínua dos dados do gerador, feita pelo Node-RED DSE — esse fluxo não muda. O Node-RED de seleção (caixa tracejada, fluxo novo ainda a construir) recebe do HTML a seleção manual/automático, direciona a escrita para o DB SNAP MANUAL (PLC dos Bancos de Carga) ou para o DB SNAP AUTO (PLC Ensaio Automático) e lê de volta o valor salvo do mesmo lugar (SB_DB SNAP) — um segundo losango, com o mesmo modo, escolhe a origem da leitura — entregando ao HTML — é isso que alimenta a tabela de resultado, com a confirmação "salva" e os valores de cada etapa. O DB SNAP AUTO existe só no PLC Ensaio Automático; o DB SNAP MANUAL, só no PLC dos Bancos de Carga. No futuro, o PLC Ensaio Automático envia o CB AUTO das Cargas ao PLC dos Bancos de Carga, que aciona as chaves dos Bancos de Carga — hoje essa ação é do operador no modo manual. Cada DB SNAP guarda os dados de um ensaio enquanto ele acontece e é sobrescrito no ensaio seguinte.
